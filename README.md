# Track Racer Remote

A family-friendly, no-build Web Bluetooth remote for Bluetooth LE toy race cars that speak the Apache-2.0 drive-sdk vehicle protocol.

- Open the page in **Google Chrome** (Mac, Windows, ChromeOS or Android). Safari/iPhone do not support Web Bluetooth.
- Press **Find & Connect a Car** (up to two cars, one card each).
- Speed slider + STOP, lane left/right, U-turn, headlights/taillights, colour patterns, battery, live piece/location IDs.
- Track type toggle: modular plastic pieces or roll-out vinyl mat.
- Try it without cars: add `?demo=1` to the URL.

Unofficial fan-made project. Not affiliated with, or endorsed by, the toy's original maker or its current owner. Protocol per the Apache-2.0 drive-sdk.
